# Protem brand assets

The mark is "Interval": two brackets closing a square, one gap still open and one nearly shut. Access as a closed interval.

## `logo/`: masters and variants

| File | What it is |
|---|---|
| `protem-symbol.svg` | The symbol, master drawing, 256×256 |
| `protem-symbol-small.svg` | Small-size cut for 16 to 24 px (wider gaps, thicker strokes); source of the favicon and app icons |
| `protem-symbol-reversed-master.svg` | Thinner drawing for dark backgrounds |
| `protem-symbol-black.svg`, `-white.svg`, `-mono-1d5fa8.svg` | One-colour symbol: black, white, Protem Blue |
| `protem-horizontal.svg` | Main lockup: blue symbol, Ink wordmark, for light backgrounds |
| `protem-horizontal-on-dark.svg` | Main lockup for dark backgrounds: light-blue symbol, white wordmark |
| `protem-horizontal-black.svg`, `-white.svg`, `-mono-1d5fa8.svg` | One-colour lockups |
| `protem-horizontal-1200.png`, `protem-horizontal-black-1200.png` | The lockup at 1200 px wide |
| `protem-stacked.svg` | Symbol above the wordmark |
| `protem-wordmark.svg` | The wordmark alone |

The wordmark is Public Sans Bold converted to outlines (SIL Open Font License 1.1). No file contains live text.

## `web/`: favicon and icon set

`favicon.ico`, `favicon.svg`, PNG icons from 16 to 512 px, `apple-touch-icon.png`, `maskable-512.png`, `site.webmanifest` and `head-snippet.html`. The UI serves copies of these from `web/public/`.

## `social/`: share images
